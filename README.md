# Aero Wizard Sample

小时候就蛮喜欢这种Aero风格的对话框，很精致，用AI做了一个出来。

## 实现以及给AI Agent的指引

其实就是系统的Areo向导对话框，适合用来做一些安装包或者向导之类的，调用系统API实现。
